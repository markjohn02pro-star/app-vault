Vault

Secure file encryption

How to use

  1. Choose to Encrypt or Decrypt a file using the tabs.
  2. Drop a file or click to browse for the file you want to process.
  3. Enter a strong password. You will need this same password to decrypt the file later.
  4. Click the Action button to start the process.
  5. Once finished, the encrypted/decrypted file will automatically download.
🛡️

All encryption runs locally in your browser. No data is ever sent to a server.
